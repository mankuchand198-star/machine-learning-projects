# Machine Learning Projects

A collection of machine learning projects and Jupyter notebooks demonstrating various algorithms, classification tasks, and data modeling techniques.

## Projects Included

1. **Iris Flower Classification**
   - **Algorithm:** Logistic Regression
   - **Notebook:** [`Iris Classification (Logistic Regression).ipynb`](./Iris%20Classification%20(Logistic%20Regression).ipynb)
   - **Description:** Multi-class classification on the classic Iris dataset predicting flower species based on sepal and petal measurements.

2. **Diabetes Prediction**
   - **Algorithm:** Random Forest Classifier
   - **Directory:** [`02_Diabetes Prediction (Random Forest)`](./02_Diabetes%20Prediction%20(Random%20Forest)/)
   - **Dataset:** `diabetes.csv`
   - **Notebook:** `Diabetes Prediction.ipynb`
   - **Description:** Binary classification predicting the likelihood of diabetes in patients based on diagnostic medical indicators.

## Getting Started

### Prerequisites

Ensure you have Python 3.8+ installed along with the required libraries:

```bash
pip install numpy pandas scikit-learn matplotlib seaborn jupyter
```

### Running the Notebooks

Launch Jupyter Notebook or JupyterLab:

```bash
jupyter notebook
```
